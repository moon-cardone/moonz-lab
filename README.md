# moonz.lab

혼자 만들고, 혼자 굴립니다.

https://moon-cardone.github.io/moonz-lab/

**여기엔 프로젝트 업데이트를 올립니다.** 공부한 것·기술 메모는 옵시디언에.

## 글 하나 올리기

**1. 파일 만들기** — `content/log/` 에 `.md` 파일을 하나 만든다.
`_template.md.txt` 를 복사해서 쓰면 편하다.

```markdown
---
date: 2026-08-06
title: 오늘 고친 것
tags: pushdown
status: 러프
---

한 줄만 써도 된다.
```

**2. 올리기** — 둘 중 아무거나.

- `publish.bat` 더블클릭
- 클로드에게 **"발행해줘"**

2~3분 뒤 사이트에 반영된다.

날짜나 제목을 빠뜨리면 **올라가지 않고 멈춘다.** 어느 파일이 문제인지 알려주니 고치고 다시 누르면 된다.

## 쓸 수 있는 값

`date` 와 `title` 은 반드시 있어야 하고, 나머지는 없어도 된다.

| 항목 | 쓰는 것 |
|---|---|
| `date` | `2026-08-06` 형식만 |
| `title` | 제목 |
| `tags` | 쉼표로 여러 개 |
| `status` | `러프` · `다듬는 중` · `정리됨` |

프로젝트는 `status` 가 `운영 중` · `만드는 중` · `멈춤` 이다.

## 프로젝트별 일지

카드를 누르면 그 프로젝트 일지만 모아둔 페이지로 간다.

일지 `tags` 에 프로젝트 이름을 그대로 적으면 그 페이지에 들어간다.

```
쓰레드 자동 포스팅 · 블로그 자동 포스팅 · 한 줄 육아
작업 기록 사이트 · pushdown · 인스타툰 공장
```

띄어쓰기가 헷갈리면 `project: 한 줄 육아` 를 써도 된다.

## 올리기 전에 눈으로 보고 싶으면

```powershell
python build.py               # index.html 다시 만들기
python -m http.server 8000    # http://127.0.0.1:8000 에서 미리보기
```

```powershell
python build.py --check       # 올리지 않고 검사만. 프로젝트별 일지 개수도 나온다
python test_build.py          # 자체 점검 19개
```
