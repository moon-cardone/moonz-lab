테셋 메이트를 별도 서버 없이 열 수 있도록 하나의 HTML로 묶었습니다. 개인 학습용 2주 과정을 담고, 시작일과 풀이 기록은 각자의 브라우저에 남도록 했습니다.

화면 코드와 필요한 자산을 파일 안에 넣어 외부 스크립트를 불러오지 않게 했습니다. 기존 답안·오답·메모는 유지하면서 학습 과정을 바꾸고, 파일 위치나 브라우저가 달라질 때를 위해 기록 백업·복원 안내도 붙였습니다.

개발 당시 로컬 서버로 파일을 연 뒤 네트워크를 차단해 채점·메모·그림 표시를 확인했습니다. 새 브라우저에서는 빈 기록으로 시작하고, 같은 브라우저로 다시 접속하면 기록이 남는 것도 확인했습니다. 파일을 더블클릭해 여는 경로 자체는 자동 검사하지 못했습니다.
